ЦКС — Робочий офіс

Файли (тримайте разом в одній папці):
index.html  — каркас сторінки
style.css   — кольори, шрифти, розміри
app.js      — уся логіка програми (таблиці, календар, таймлайн, терміни, нагадування)
ai.js       — помічник: локальні команди + режим «ШІ» (нейромережа) з діями за підтвердженням (база типових планів — угорі файлу)
ai-assistant-function.ts — шаблон сервера для режиму «ШІ» (Supabase Edge Function), див. шапку файлу
config.js   — налаштування бази даних (адреса та ключ Supabase)
schema.sql  — схема бази даних (виконати один раз у Supabase)
migration_v2.sql — оновлення вже створеної бази (нові посади). Потрібен, якщо schema.sql вже виконували раніше
migration_v3.sql — оновлення вже створеної бази: коментарі та доступ за посиланням (після migration_v2.sql)
migration_v4.sql — оновлення вже створеної бази: профіль користувача (фото, телефон). Виконати після migration_v3.sql
Img/        — іконки та логотип (SVG). Старі PNG-іконки більше не потрібні; фон меню «окно_выбора_опций.png» лишається

Режими роботи
1) config.js порожній — дані зберігаються тільки в браузері (для перегляду дизайну).
2) config.js заповнено — акаунти, відділи, задачі й файли зберігаються в базі,
   усі користувачі бачать одні й ті самі дані в реальному часі.

Увімкнення бази (Supabase, безкоштовний тариф підходить для старту)
1. supabase.com → New project. Дочекайтесь створення.
2. SQL Editor → New query → вставте вміст schema.sql → Run.
3. Project Settings → API: скопіюйте Project URL та anon public key у config.js.
4. Authentication → URL Configuration: у Site URL вставте адресу вашого сайту
   (для листів підтвердження та відновлення пароля).
5. Authentication → Providers → Email: за бажанням увімкніть/вимкніть
   «Confirm email» (підтвердження пошти).
6. Завантажте всі файли на хостинг (GitHub Pages / Netlify) і зареєструйтесь.
   Перший зареєстрований користувач отримує повний доступ.

Посади
- Начальник: створює відділи, керує доступом.
- Проєктний менеджер: працює у відділі, може керувати доступом співробітників.
- Помічник проєктного менеджера і Помічник: працюють із задачами та проєктами свого відділу.
  При реєстрації всі, крім начальника, обирають відділ зі списку.

Терміни проєкту та нагадування
- Сторінка «Проєкти» → «Графік термінів»: термін (напр. «Термін доставки МК», дата) створює віху,
  автозадачу з цією датою («Відвантажити останню машину по МК 17.10.2026») та нагадування.
- Шаблони термінів → посилання «Шаблони термінів» у картці проєкту.
- Дзвіночок угорі: прострочене, сьогодні, найближче. Сповіщення браузера — на ваш дозвіл (працюють, поки сайт відкритий).
- «У календар (.ics)» — файл для Google/Outlook/телефону зі справжніми будильниками, що спрацюють і без сайту.

Локальний помічник (кнопка «✦ Помічник» унизу праворуч)
Працює у браузері, без інтернету й без зовнішніх сервісів. Це помічник на правилах, а не нейромережа.

Коментарі до задач
- У боковому вікні задачі → «Коментарі». Можна адресувати конкретному співробітнику, всім виконавцям задачі
  або лишити без адресата; позначка «лише адресату» робить коментар приватним (бачать автор і адресат).
- Адресат бачить коментар у дзвіночку («Коментарі для вас») і спливаюче повідомлення; у таблиці біля задачі стоїть значок 💬 N.

Доступ за посиланням (як у Google Диску)
- Боковe вікно задачі → «Поділитися»: створіть посилання з роллю «Перегляд», «Коментування» або «Редагування»
  (термін дії: без обмеження / 7 / 30 днів). Посилання можна вимкнути хрестиком.
- Той, хто відкриває посилання, акаунта не потребує й бачить лише цю задачу. Приватні та адресні коментарі гостям не показуються.
- Для роботи посилань між різними комп’ютерами потрібна база даних (config.js + schema.sql / migration_v3.sql).

Оновлення інтерфейсу (v4)
- Задачі: групуються за категоріями (не за проєктами). Порядок: В процесі → Постійна → Не почато → Прострочено → Виконано;
  усередині групи — за пріоритетом («Важлива», «Середня», «Неважлива») і датою кінця. Виконані завжди внизу.
  Галочки вибору рядків з’являються при наведенні на задачу.
- Коментарі не показуються в списку: клікніть по значку коментарів біля задачі (у таблиці або в картці задачі) — вікно відкриється; повторний клік закриє.
- Календар: лише для проєктів (смуги проєктів і прапорці термінів). Бачать начальник, проєктні менеджери та їхні помічники.
  Подвійний клік по дню додає термін проєкту (створюється задача й нагадування).
- Центр управління — конструктор: кнопка «Налаштувати центр» (для начальника та проєктних менеджерів) дозволяє додавати,
  прибирати, перейменувати блоки, змінювати їхню ширину та порядок (перетягуванням), додавати нотатки й лічильники за фільтром.
- «Ризик зриву строків» показує задачі та терміни проєктів, до кінця яких залишився 1 день.
- Акаунт: клік по імені у лівій панелі — фото, ім’я, телефон, «про себе», зміна пароля.
  Для роботи профілю в базі виконайте migration_v4.sql.

Оновлення помічника (усе в ai.js)
Нові команди (працюють без інтернету):
- «Познач «назва» виконаною / в процесі / не розпочатою»
- «Перенеси «назва» на 3 дні / на тиждень / на 20.11»
- «Признач «назва» Олені, Івану» (слово «замість» замінює виконавців, інакше — додає)
- «Коментар до «назва» для Олени: текст»
- «Заархівуй «назва»» · «Постав «назва» важлива / середня / неважлива»
- «Мій план на тиждень / на місяць», «План відділу на тиждень», «Що прострочено?», «Дайджест за тиждень»
- «Стан проєкту …», «Знайди …»
Усі зміни спершу показуються карткою з галочками; нічого не виконується без кнопки «Виконати вибране».

Режим «ШІ» (нейромережа, за бажанням)
1. Розгорніть ai-assistant-function.ts (кроки — у шапці файлу) і додайте ключ ANTHROPIC_API_KEY на сервері, не в браузері.
2. У config.js додайте AI_ENDPOINT:'https://<ваш-ref>.supabase.co/functions/v1/ai-assistant'
3. У панелі помічника з’явиться перемикач «ШІ ✓ / Лок.». Для точних розрахунків (аналіз процесів, «що на сьогодні», дайджест,
   прострочені) помічник у будь-якому режимі використовує локальну логіку; решту запитів вільною мовою обробляє ШІ.
4. Приватність: у режимі «ШІ» на ваш сервер, а звідти до ШІ-сервісу, надсилаються назви задач, проєктів, імена співробітників
   і дати вашого відділу. Коментарі та вкладення не надсилаються. Якщо ШІ недоступний, помічник відповідає локально.

Діалог і розвиток помічника (блок «Діалог і пам’ять» у кінці ai.js; працює в обох режимах)
Діалог
- Помічник пам’ятає, про що йшлося: після «Знайди виставка» можна писати «познач її виконаною», «перенеси на 3 дні», «коментар: …».
- Якщо не вистачає даних, він перепитує й чекає відповідь: «Кому призначити?» → «Олені»; «На скільки перенести?» → «на 3 дні».
- На картку з діями можна відповісти словом «так» (виконати) або «ні» (скасувати). Кнопки в картці працюють як і раніше.
- Дрібна розмова: «дякую», «як справи?», «хто ти?». У режимі «ШІ» на це відповідає нейромережа.
- Кнопка ⟲ угорі панелі або команда «нова розмова» скидає контекст (пам’ять лишається).
- У режимі «ШІ» діалог іде справжньою історією (до 16 реплік), ШІ знає, що ви підтвердили чи виконали, і може пропонувати кнопки-підказки.
Розвиток (пам’ять зберігається в браузері, окремо для кожного користувача)
- «Запам’ятай: Олена відповідає за КП» — нотатка (її враховує й ШІ).
- «Запам’ятай команду «ранок» = «що на сьогодні?»» — власні скорочення.
- Плани, які ви відредагували й застосували («Розпиши план…»), запам’ятовуються й пропонуються першими для схожих задач.
- 👍 / 👎 під відповіддю. На 👎 помічник питає, що мало бути, і зберігає це як виправлення (бачить і ШІ).
- Запити, які ви повторюєте, з’являються кнопками швидкого доступу.
- «Що ти пам’ятаєш?» (або кнопка 🧠) · «Забудь …» · «Очисти пам’ять».
- Приватність: у режимі «ШІ» разом із даними відділу на ваш сервер, а звідти до ШІ-сервісу, надсилаються нотатки,
  назви команд, вивчені плани й виправлення з пам’яті помічника. Якщо цього не хочете, користуйтеся режимом «Лок.».
- Оновіть також ai-assistant-function.ts (версія 2) і розгорніть його знову: supabase functions deploy ai-assistant.
